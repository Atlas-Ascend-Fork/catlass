## `tla.VectorSSA.generate_mask`

**Source:** [`catlass.core_api.VectorSSA.generate_mask`](../../../../../catlass/core_api.py)

Description:

Build a mask from a data block of this register, wrapping Ascend C
`MaskGenWithRegTensor` (hardware instruction `MOVVP`).

`MaskGenWithRegTensor` is a Reg data-load interface: it reads a
`RegTensor` and produces a `MaskReg`. The register is treated as a
sequence of data blocks ordered by element and then by in-element
bit (LSB first). `offset` selects one block, and each bit of that
block becomes one predicate lane. The element width fixes both the
block width and the block count:

- b32 source: the 2048-bit register splits into 32 blocks of
  8Byte (64 bits), so `offset` is `0..31`. The result is a
  `mask<64>` whose lane `L` is register bit `64 * offset + L`.
- b16 source: the register splits into 16 blocks of 16Byte
  (128 bits), so `offset` is `0..15`. The result is a `mask<128>`
  whose lane `L` is register bit `128 * offset + L`.

Physically the 32Byte `MaskReg` gives each element 2 bits (b16) or
4 bits (b32); the selected bit is broadcast to those bits, and only
the lowest one is effective.

Prototype:

```python
tla.VectorSSA.generate_mask(offset: int) -> 'MaskSSA'
```

Parameters:

- `offset` (`int`): Compile-time block index. Required. `0..15` for
  a b16 register and `0..31` for a b32 register.

Constraints:

- Supports Ascend 950 (`--npu-arch 3510`) only.
- Must be called inside a `@tla.kernel`-decorated kernel function.
- Must be called inside `tla.vec.func(mode="simd")`.
- Element type must be 16-bit or 32-bit (i16/u16/f16/bf16,
  i32/u32/f32); b8 and b64 are unsupported.
- `offset` must be a compile-time Python int within the block range.

Example:

```python
with tla.vec.func(mode="simd"):
    bits = src_tile.load()      # !tla.vector<64xf32>
    m = bits.generate_mask(0)   # !tla.mask<64>
```

## `tla.create_mask`

**Source:** [`catlass.core_api.create_mask`](../../../../../catlass/core_api.py)

Description:

Create a vector mask from a fixed pattern (`tla.mask.*` tokens).

Prototype:

```python
tla.create_mask(*, pattern: _MaskPattern | str | None = None, dtype: DTypeLike = Float32) -> MaskSSA
```

Parameters:

- `pattern` (`_MaskPattern | str | None`): Mask pattern token or its name
  string. Required at runtime (`None` raises). Tokens live under
  `tla.mask`:

  | Pattern | Meaning |
  |---|---|
  | `ALL` | All elements are valid |
  | `ALLF` | All elements are invalid |
  | `VL1` / `VL2` / `VL3` / `VL4` | Lowest 1 / 2 / 3 / 4 elements are valid |
  | `VL8` / `VL16` / `VL32` / `VL64` / `VL128` | Lowest 8 / 16 / 32 / 64 / 128 elements are valid |
  | `M3` | Elements whose index is a multiple of 3 are valid |
  | `M4` | Elements whose index is a multiple of 4 are valid |
  | `H` | Lowest half of the elements are valid |
  | `Q` | Lowest quarter of the elements are valid |

- `dtype` (`DTypeLike`): Element type associated with the mask (also decides
  how many elements fit in one vector: 256 bytes / element size). `Bool`
  is b8-width → `!tla.mask<256>`. Optional, default `Float32`.

Constraints:

- Must be called inside a `@tla.kernel`-decorated kernel function.
- Must be called inside `tla.vec.func()`; `pattern` is required.
- Ops that take `mask=` need a `MaskSSA` from `create_mask` /
  `update_mask`, not a raw `tla.mask.*` token.
- `VectorSSA[tla.Bool]` is single-VL and move-only (load/store); it
  cannot be used for arithmetic / cast.

Example:

```python
with tla.vec.func(mode="simd"):
    # Build masks from pattern tokens:
    m_all = tla.create_mask(pattern=tla.mask.ALL, dtype=tla.Float16)
    m_tail = tla.create_mask(pattern=tla.mask.VL8, dtype=tla.Float16)
    m_bool = tla.create_mask(pattern=tla.mask.ALL, dtype=tla.Bool)  # mask<256>
    # Before: x_reg / y_reg are full vectors; only the lowest 8 elements add.
    z = tla.add(x_reg, y_reg, mask=m_tail)
    # After: valid elements hold x+y; masked-out elements stay inactive.
```
